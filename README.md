# PDF Name Analyzer

**A lightweight Python application for processing PDF documents and counting/searching names through a Streamlit interface.**

## Overview

This project turns a focused document-processing script into a small interactive application. It provides a practical workflow for analyzing PDF content and identifying/counting names without requiring the user to work directly with Python code.

## Components

- `Conta_Nomes_em_PDF.py` — core PDF/name-processing logic
- `API_usandoStreamlit.py` — Streamlit application layer
- `requirements.txt` / `packages.txt` — runtime dependencies

## Architecture

```text
PDF Input
   ↓
Python Processing Logic
   ↓
Name Search / Counting
   ↓
Streamlit Interface
   ↓
User Results
```

## Tech Stack

`Python` · `Streamlit` · `PDF Processing` · `Text Analysis`
